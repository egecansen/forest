# hektor console

GUI console for the Hektor flaky-triage kit (forked from the şahika shell).

- Run history + config live under `~/.hektor-console/` (override with `HEKTOR_CONSOLE_HOME`).
- Dev: `npm run install:all` then `npm run dev` (server :8765, Vite :5173).
- Tests: `npm --prefix client test` · `npm --prefix server test`
- Production: `npm run build && npm start`

Full usage docs land with the e2e task.
